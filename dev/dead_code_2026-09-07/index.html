C. Alias de compatibilidad en models/__init__.py¶

El bloque # Temporary compatibility aliases while callers migrate to the new schema. (L34-41) es de dos clases distintas:

Borrables ya (nadie los importa):

  • LigandRecord = MoleculeRecord
  • ReceptorRecord = MoleculeRecord
  • MoleculeDescriptorRecord = DescriptorVectorRecord

(Quitar también sus entradas de __all__.)

Todavía en uso — requieren una pasada de renombrado, no un borrado:

  • DockingResultRecord → DockingResult
  • ActivityRecord → LigandActivity
  • QSARModelRecord → QSARModel
  • QSARPredictionRecord → QSARPrediction

Es sustitución mecánica del nombre en los sitios de uso y después borrar el alias; el modelo real no cambia.

D. Público pero nunca importado fuera de su propio módulo (93)¶
