# Main analysis tools

AMDockVS has two main analysis tools: **Docking Studio** for preparing,
configuring and launching docking runs, and **QSAR** for training models and
scoring molecules. Each guide follows the corresponding workspace panels and
describes their controls.

## Docking Studio

Use Docking Studio to choose docking programs, prepare ligands and receptors,
review the docking scope, and launch runs. See the [Docking Studio guide](docking_studio.md)
for the step-by-step workflow.

## QSAR

Use QSAR to build models from activity data, predict activities for project
ligands or screening shards, and review model results. See the [QSAR guide](qsar.md)
for model building, prediction and analysis.
